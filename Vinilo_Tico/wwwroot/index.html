Vinilo Tico API

API del catálogo de álbumes de la tienda Vinilo Tico.

MétodoRutaDescripciónRespuesta
GET/api/AlbumLista los álbumes (filtro opcional ?artista=)200
GET/api/Album/{Id}Obtiene un álbum por Id200 / 404
POST/api/AlbumCrea un álbum201
PUT/api/Album/{Id}Edita un álbum204 / 404
DELETE/api/Album/{Id}Elimina un álbum204 / 404
